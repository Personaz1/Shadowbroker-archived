# Shadowbroker — Archived OSINT Dashboard Fork

> **Archive notice:** This is a modified fork of the upstream Shadowbroker project. It is retained as a historical OSINT dashboard experiment, not as a maintained intelligence service.

## Provenance
This repository is a fork of [johan-martensson/Shadowbroker-archived](https://github.com/johan-martensson/Shadowbroker-archived), itself based on earlier Shadowbroker work. See the upstream repository and the AGPL-3.0 license for source provenance and obligations.

## Historical scope
The fork experimented with combining publicly available aviation, maritime, satellite, geospatial, infrastructure, environmental and news feeds in one map-oriented interface. Data availability, provider terms, accuracy and update latency vary by source.

## Responsible-use boundary
Public availability does not make every use appropriate. Do not use this software to stalk, harass, dox or target private individuals, or to infer sensitive personal movements. Respect provider terms, privacy law, export controls and local restrictions. Avoid publishing precise sensitive-site or personal tracking outputs.

## Status
Historical fork; no active maintenance or operational support is promised. The presence of a data connector does not guarantee that it still works, that its source is reliable or that the displayed information is current.

## Running and modifying
This README intentionally avoids presenting the fork as a current turnkey service. Review the source, upstream license, data-source terms and security posture before any controlled research use. Do not expose dashboards or API credentials publicly.
